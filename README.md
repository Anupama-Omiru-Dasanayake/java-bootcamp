# Java Bootcamp

A structured **Core Java learning repository** covering Java fundamentals, OOP, collections, file I/O, modern Java, multithreading, data structures, algorithms, JDBC, and practical projects.

## Goal

Build a strong Java foundation from beginner level to advanced concepts through small, focused examples and progressively larger projects.

## Projects

Projects are divided into three levels:

- **Beginner** — basic syntax, conditions, loops, methods and input/output
- **Intermediate** — OOP, collections, exceptions and file handling
- **Advanced** — larger applications combining multiple Java concepts and JDBC

## Project Rules

- Keep package names lowercase.
- Use `PascalCase` for classes.
- Use `camelCase` for variables and methods.
- Use `UPPER_SNAKE_CASE` for constants.
- Keep examples focused on one concept whenever possible.
- Add practice programs after learning each major concept.
- Build projects after completing related topics.

## Scope

This repository focuses on **Core Java**.

It intentionally does not include:

- Maven
- Spring Framework
- Spring Boot
- Spring MVC
- Spring Security
- Hibernate/JPA
- Microservices

Those will be handled as separate projects after the Core Java foundation is complete.
